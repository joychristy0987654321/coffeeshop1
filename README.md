# ☕ Coffee Haven

A modern and responsive **coffee shop website** built using **React.js and Vite**. Coffee Haven allows customers to explore coffee products, add items to their cart, manage favourites, place orders, and complete payments. It also includes an **Admin Dashboard** for managing coffee products and customer orders.

## 🌟 Features

### 👤 Customer Features

* 🏠 Home page with attractive coffee shop design
* ☕ Browse coffee menu
* 🔍 View coffee details
* 🛒 Add coffee products to cart
* ❤️ Add/remove favourite coffee items
* 📦 Place and manage orders
* 💳 Checkout and payment page
* 🔐 Customer login
* 📱 Responsive design for different screen sizes

### 👨‍💼 Admin Features

* 📊 Admin dashboard
* ➕ Add new coffee products
* ✏️ Edit existing coffee products
* 🗑️ Delete coffee products
* 📦 View customer orders
* 📈 View sales/order reports
* 🖼️ Manage coffee product images

## 🛠️ Technologies Used

* **React.js**
* **Vite**
* **JavaScript**
* **HTML5**
* **CSS3**
* **React Router**
* **REST API**
* **Local Storage**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project

```bash
cd coffee-haven
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run locally using the Vite development server.

## ☕ About Coffee Haven

**Coffee Haven** is a modern coffee shop website created to provide customers with a simple and enjoyable online coffee-ordering experience.

Customers can explore different coffee products, manage their cart and favourites, place orders, and make payments through the website.

The admin section helps the shop administrator manage coffee products, update product information, delete products, and view customer orders and reports.
